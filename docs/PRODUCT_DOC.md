## 一、产品定位

**TradeAI Pro** 是一款专为 B2B 外贸从业者设计的 AI 生产力工作台。

核心价值：将外贸日常工作中的邮件撰写、文案创作、报价计算、客户管理、单证生成等耗时任务，通过 AI 压缩到 30 秒内完成。

**目标用户：** 外贸 SOHO、业务员、外贸经理、跨境电商卖家、工厂外贸部

---

## 二、技术架构

| 层级 | 技术栈 |
|------|--------|
| 前端 UI | Streamlit 1.45（Python 全栈） |
| AI 引擎 | NVIDIA NIM API（Meta Llama 3.3 70B） |
| 数据持久化 | JSON 文件（per-user 隔离，原子写入） |
| PDF 生成 | fpdf2（报价单/装箱单/商业发票/形式发票） |
| 认证 | PBKDF2-HMAC-SHA256（10万次迭代） |
| 支付 | Stripe Checkout Sessions |
| 邮件 | SMTP（stdlib smtplib） |
| 部署 | Streamlit Cloud / Railway |
| CI/CD | GitHub Actions（ruff + pytest + auto-merge） |

## 四、AI 质量提升系统

### 4.1 用户偏好持久化 (`utils/user_prefs.py`)

| 偏好项 | 作用 |
|--------|------|
| company_name / contact_name / email / phone | 全站表单自动预填 |
| default_product / default_language / default_tone | 默认值免重复选择 |
| ai_style_tone | 全局 AI 语气（专业/友好/正式/简洁） |
| ai_response_length | 全局回复长度（简短/中等/详细） |
| ai_custom_instructions | 每次生成自动追加的自定义指令 |
| ai_forbidden_words | AI 避免使用的词语列表 |

### 4.2 多轮对话 (`utils/conversation.py`)

- 开发信 + 询盘回复支持生成后**连续多轮修改**
- 4 个快捷修改按钮 + 自由文本指令
- 对话历史展示（最近 6 轮）
- 自动 trim 防 token 溢出（最大 10 轮）

### 4.3 批量生成 (`pages/24_🔁_批量生成.py`)

- 同一产品一键生成 2-10 封风格各异的开发信
- 8 种心理策略可选：开门见山/痛点共鸣/数字证明/好奇心/社会认同/紧迫感/问题导入/故事叙述
- 主题行对比表 + 全量下载

## 七、部署指南

### Streamlit Cloud（推荐）

1. Fork 仓库到你的 GitHub
2. 访问 [share.streamlit.io](https://share.streamlit.io) → New app
3. 选择仓库，主文件 `app.py`
4. Secrets 中填入 `NVIDIA_API_KEY`
5. Deploy（1-2分钟）

### 本地开发

```bash
pip install -r requirements.txt
cp .env.example .env  # 填入 NVIDIA_API_KEY
streamlit run app.py
```
